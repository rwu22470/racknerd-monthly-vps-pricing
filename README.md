## 月付和年付的差价出在什么地方

按月计费的入门档 $27.59/月，跑满一年是 $331。年付特价线的入门款折算月均约 12 元人民币。两者配置、系统授权、硬盘类型都不一样，不能当成同一台机器的两个报价来比，但价格量级差得很明显。

差价的本质是付款方式：年付把 12 个月的钱一次交出去，商家拿到现金流，愿意让出一大截折扣；月付卖的是随时能停的自由，这份自由单独计价。所以月付单价高不奇怪，奇怪的是有人月付用了两年才发现，同样的钱够开好几台年付机器。

按这个逻辑，能算出一条清晰的路径：

1. 新项目、第一次用这家、线路没把握，先月付 1 个月，成本几十美元，试错上限封死
2. 一个月后确认延迟、稳定性、IO 都能接受，转年付特价线重新下单，长期成本立刻降一个量级
3. 项目本身就是短期的，或者用量随时可能变，继续月付，别为了省那点钱把自己绑一年

## 按用途挑档位

**只建站、挂探针、跑轻量脚本**：最低档就够。一个静态站或轻量 WordPress，1GB 内存的余量很充裕，多花的钱买不到你实际需要的东西。

**要 Windows / 远程桌面**：直接看上面那张表，按并发用户数和要装的软件选内存，4GB 和 8GB 是最常用的两档。

## 下单前需要确认的几件事

支付方式。官网结账页支持哪些付款渠道，下单前看清楚，别等到付款环节才发现卡住。

退款政策。具体天数、是否要满足流量条件、用了优惠是否还生效，都在官方条款里，页面上没写明的部分开工单问。

机房选择。同一档套餐不一定所有机房都有货，缺货时可选列表会缩短，先确认你要的机房还在。

续费周期和续费价。RackNerd 特价线是续费同价，月付线按月续，转年付需要重新下单而不是在后台改周期，别指望一键切换。

是否需要 CN2。如果需要国内低延迟，这台机器从第一步就选错了，后面的配置都是白搭。
